# SEABAR — Sitio Web

## Cómo subir a GitHub Pages

1. Crea un repositorio en GitHub (ej. `seabar`)
2. Sube TODOS estos archivos a la raíz del repo
3. Ve a Settings → Pages → Branch: main → Save
4. Tu web quedará en: `tuusuario.github.io/seabar`

## Archivos
- `index.html` — página principal
- `styles.css` — estilos
- `script.js` — animaciones, audio, tabs
- `logo.png` — logo sin fondo
- `barrita.png` — foto de la barrita sin fondo
- `empaque.png` — empaque blanco sin fondo
- `beach.svg` — fondo playa animado

## Para agregar fotos reales de clientes
En `index.html`, busca los comentarios `<!-- FOTO REAL -->` 
y reemplaza los divs de gradiente con `<img src="tu-foto.jpg">`.
